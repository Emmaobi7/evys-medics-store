# evys-medics-store

**EVYS Medical** — Medical & Laboratory Supplies E-Commerce Platform.

## Overview
EVYS Medical is a clean, modern B2B/B2C medical and laboratory supplies procurement interface featuring:
- Mega Menu departmental navigation (Medical Equipment, Laboratory Equipment, Consumables, Healthcare & Workwear)
- Real-time catalog search with multi-field matching (Name, SKU, Brand, Category)
- Quick Order SKU lookup & multi-item bulk procurement
- Ex-VAT and Inc-VAT dynamic pricing transparency
- Product Detail specifications and warranty tables
- Fully responsive, accessible, and high-performance UI

## Tech Stack
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Vanilla CSS Design Tokens
- **Icons**: Lucide React

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
